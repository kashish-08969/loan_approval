# Loan Approval Prediction — Google Colab + GitHub + Streamlit

This project trains a Random Forest model in Google Colab and runs a web app
using Streamlit Community Cloud.

## Files

- `app.py` — Streamlit website.
- `requirements.txt` — Python packages needed by Streamlit Cloud.
- `loan_approval_training.ipynb` — training notebook for Google Colab.
- `loan_model.joblib` — generated by the notebook; add this to the GitHub repo
  after training if you want the deployed app to work without uploading the
  model manually each time.

## Part A — Train the model in Google Colab

1. Open https://colab.research.google.com/
2. Select **File → Upload notebook** and upload `loan_approval_training.ipynb`.
3. Run each cell from top to bottom.
4. When asked, upload the dataset CSV file named similar to
   `loan_approval_dataset.csv`.
5. The last cell downloads `loan_model.joblib` to your computer.
6. Keep the file. You will use it in the GitHub repository.

The notebook expects these dataset columns:
`no_of_dependents`, `education`, `self_employed`, `income_annum`,
`loan_amount`, `loan_term`, `cibil_score`, `residential_assets_value`,
`commercial_assets_value`, `luxury_assets_value`, `bank_asset_value`,
`loan_status`.

## Part B — Upload project to GitHub

1. Sign in to https://github.com/ and create a new repository, for example
   `loan-approval-predictor`.
2. Upload `app.py`, `requirements.txt`, and `loan_model.joblib`.
3. Upload the notebook too if you want to keep your training work with the
   project.
4. Make sure `app.py`, `requirements.txt`, and `loan_model.joblib` are at the
   top level of the repository, not inside another nested folder.

Do not upload the original dataset if it contains personal or confidential data.
For a public school project, use a public/sample dataset and check its licence.

## Part C — Deploy with Streamlit Community Cloud

1. Open https://share.streamlit.io/ and sign in with GitHub.
2. Choose **Create app**.
3. Select your repository and branch (usually `main`).
4. Set the main file path to `app.py`.
5. Click **Deploy**.
6. Wait for the build to finish. Streamlit will install packages from
   `requirements.txt` and launch the app.
7. Open the generated website link.

If you have not added `loan_model.joblib` to GitHub, the app will show a model
upload box. You can upload the model file there to make predictions.

## Local test (optional)

In a terminal opened in this folder:

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

## Important model compatibility note

The model is serialized with joblib. The scikit-learn version used in Colab
and the version installed by Streamlit should ideally match. The notebook
prints the Colab scikit-learn version. If deployment reports a version warning
or model-loading issue, pin that exact version in `requirements.txt`, e.g.
`scikit-learn==1.5.2` (replace with the version printed by your Colab run),
then commit the changed file and let Streamlit redeploy.

## Disclaimer

This is an educational prediction project. It does not make real lending
decisions and should not be used to decide whether someone should receive a loan.
